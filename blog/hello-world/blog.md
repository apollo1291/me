This is a sample post. To add a new entry, create a folder under `blog/` with a `blog.md` file and any images alongside it.

You can embed images with markdown:

![placeholder](https://placehold.co/400x200/111/fff?text=hello+world)

Or with raw HTML (tags must start at column 0, not indented):

<p align="center">
<img src="https://placehold.co/300x150/222/fff?text=centered" alt="centered example" width="300">
</p>

Push to GitHub and it shows up on the blog index automatically.
